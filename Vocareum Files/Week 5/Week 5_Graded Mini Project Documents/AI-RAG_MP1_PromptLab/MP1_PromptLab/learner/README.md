# MP1 — Prompt Lab

This project compares four prompting strategies for a structured extraction task using the starter template:

- Zero-shot
- Few-shot
- Structured / role-based
- Chain-of-thought (CoT)

The experiment evaluates the strategies using accuracy, parse rate, LLM judge score, cost, and latency.

## Files

### `mp1_prompt_lab.ipynb`
End-to-end implementation comparing the four prompting strategies using the starter template.

### `mp1_comparison.md`
Summary comparison table showing performance metrics.

### `mp1_writeup.md`
One-page reflection discussing findings and recommendations.

### `requirements.txt`
List of Python packages used.

## Running the Project

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Open and run `mp1_prompt_lab.ipynb` to execute the experiment and generate the results.

## Interpreting the Results

The results should be interpreted in the context of the specific task and dataset. They are not intended to establish that one prompting strategy is universally better than another.
